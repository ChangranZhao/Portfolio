# 蓝印之境 Full Project 页面设计

用户选择：研究与作品结合。相比以大图为主的画廊，这一方向用作品图像解释交互体验，并将论文方法与验证嵌入项目叙事。

## 页面结构

1. 开场：蓝印之境 / Blue Calico Realm、大幅装置全景、项目一句话概念。
2. 研究问题：如何将蓝印花布的抽象美学转化为身体可感知的交互体验。
3. 文化主题：含蓄、质朴、生命力、时间性，以四个简洁版块呈现。
4. 设计方法：将 ECMF 的动作形式、意义映射、工具与材料关系画成网页图解；用四阶段流程连接动作、感知运动基础、文化意义联想和非遗审美感知。
5. 作品体验：按论文中的三个场景组织现有图片和说明，交替使用宽幅图片与双栏文字。具体动作与场景名称以论文正文为准。
6. 研究验证：说明 22 人被试内比较的设置、具身与低具身条件，以及论文报告的主要发现。仅使用已核对的统计信息，不编造数据图。
7. 反思与论文：归纳设计启示和研究边界，提供原始 PDF 阅读入口。

## 视觉与实现

沿用现有网页技术与 Full Project 入口。黑底、白字、靛蓝强调色；大标题、章节编号、充分留白，图片与研究文字交错。桌面双栏、手机单栏，图解在小屏可顺序阅读。文字语言遵循现有站点切换方式。

## 范围与核验

仅补充此项目详情，复用四张现有项目图与论文。个人职责、项目年份、发表状态等未核实信息不补写。检查入口、论文链接、资源路径、移动端布局及站点构建。
