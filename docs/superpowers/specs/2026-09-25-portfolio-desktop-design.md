# macOS 风格个人作品集：设计说明

## 已确认的目标
依据用户提供的“Slide 16_9 - 1.png”制作可操作的个人作品集网站。桌面作品图标可点击查看内容，菜单、Dock 和窗口提供实际交互及动效。用户已同意整体方向，并授权读取同目录素材，后续会继续补充整理图片。

## 视觉与布局
以参考图为主：灰色人物背景、顶部半透明菜单栏、散布的作品缩略图、右上角 PORTFOLIO 标题窗口和底部磨砂 Dock。优先使用用户提供的背景与图标，不替换成无关图库。宽屏保留参考图构图；窄屏将作品排为可滚动网格，窗口适配屏幕，Dock 可横向浏览。

## 可操作内容
- 作品图标单击或键盘 Enter 打开详情窗口；再次打开已有窗口时将其置顶。
- 详情展示项目名称、已有介绍与图片画廊，支持上一张、下一张与大图查看。
- 窗口支持标题栏拖动、关闭、最小化、最大化及恢复；最小化的窗口可从 Dock 恢复。拖动范围保证标题栏始终可找回。
- 顶部个人菜单打开个人介绍及参考图中已有的信息；作品入口显示作品列表。状态区提供时间及显示偏好等对应面板，所有按钮均有明确反馈。
- Dock 软件图标打开相应工具介绍及已确认关联的作品；照片打开图片浏览，终端提供有限的站内导航指令，废纸篓显示空状态，不操作用户文件。
- PORTFOLIO 标题窗口可拖动；关闭后可通过作品入口重新打开。
- 支持键盘操作、可见焦点、Esc 退出浮层和减少动态效果偏好。

## 动效
Dock 悬停放大、图标点击轻弹、窗口打开及关闭过渡、最小化收回、图片切换淡入。动效保持短促，不阻挡操作；触屏不依赖悬停。

## 素材与内容约定
原始素材目录：`C:/Users/20135/Desktop/留学申请/作品集/素材`。源素材只读使用，网站所需副本放入网站资源目录。建议每个项目一个目录，图片以 `cover`、`01`、`02` 等命名，说明文字可放入同目录文本文件；这只是整理建议，不是强制要求。

当前已找到背景、12 个 Dock 图标、额外图片与两张参考图，尚未找到各项目独立图片和介绍。已有图片仅在确认所属项目后建立关联；参考图中可辨认的名称可用于入口。缺失介绍显示“项目介绍待补充”，不编造经历、获奖信息、项目过程或联系方式。用户后续补充素材后重新扫描并更新，不声称文件已自动同步。

## 实现结构与边界
网站位于“建站”目录。分开管理项目内容、桌面布局、窗口状态、Dock 和图片浏览组件。窗口状态包括打开、最小化、最大化、位置及层级；重复打开不产生重复窗口。静态作品集不需要登录或数据库。文件夹新增素材需要重新导入网站并更新预览，浏览器不会直接访问用户整个磁盘。

## 验证与交付
检查每个可点击入口的响应、窗口置顶与恢复、画廊切换、键盘操作、移动端滚动和图片加载。以宽屏截图对照参考图，验证页面无意外横向溢出。先交付可操作预览及本地源文件；若项目图片仍未补齐，清楚说明内容待补充，不将占位内容称为完整作品集。
